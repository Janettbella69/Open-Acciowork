# Provider 数据区域与传输提示

对应 PRD §3.9：选择 Provider 时明确提示数据区域与跨境传输。

| 要求 | 状态 |
| --- | --- |
| 模型选择时显示配置端点与区域 | delivered：工作区列表与选中后输入区使用同一展示组件；选择后仍可查看 |
| 设置与预检前了解数据去向 | delivered：每份 Profile 展示说明，编辑 Base URL/Region 时即时更新预览 |
| 不将配置标签冒充驻留认证 | delivered：区域标明由管理员填写；未填写、环境占位值、失效 Profile 和 Auto 分别提示未知原因 |
| 中英文传输范围说明 | delivered：消息、Agent 上下文、已批准记忆、文件内容和工具结果；提示工具服务自身的数据去向 |
| 实际处理/存储地点、区域强制和供应商条款认证 | deferred：需要部署出口策略、真实供应商合同与验收；本界面不提供此认证 |

`ProviderProfile.region` 继续作为管理员填写的说明，未改变 API 或运行时。
它不是 IP 定位结果，也不是后台强制的驻留策略。预检成功、production-eligible
标记和 API 地址均不能单独证明数据处理或存储地点。

展示端点只使用可识别 HTTP(S) URL 的 origin，省去用户名、密码、路径、query
与 fragment，不生成外部跳转链接。配置为空时标明 Anthropic 默认端点；不可识别的
地址展示未知，不回显原文。编辑表单保留操作者填写的完整配置用于修改。

`unspecified`、空白、`unknown` 和环境生成的占位区域显示“未注明”。自定义区域
按原文展示并标明来源。选择 Auto 时由服务端按原规则选择 Provider；界面不根据
列表顺序推测区域，而提示需要发送前核对时选择具体模型。已选 Profile 消失时，
展示无法取得配置，不回落到默认地区。继续沿用现有 Provider 可运行门禁。

可见提示明确模型请求可能涉及跨境传输；展开内容说明实际共享范围和代理转发，
以及搜索、浏览与连接工具有各自的数据流。选择模型不会自动限制这些工具的区域。
这不构成法律结论，也不记录新的同意书或替换已有授权。

依据是本仓固定实现 `providers.py` 的 worker 环境构建，以及本地官方文档快照
[`secure-deployment.md`](claude-agent-sdk/secure-deployment.md) 中 `ANTHROPIC_BASE_URL`
仅路由模型请求、代理可继续转发的约定；没有据域名推断任何厂商当前的数据驻留地。

中文；工作区集成验证菜单关闭后仍显示所选目标，设置集成验证编辑预览及保存区域。

# Shopify 店铺数据的边界与核对

## 能读到什么

- 店铺：名称、myshopify 域名、币种、国家/地区代码，以及应用实际获得的权限（`granted_scopes`）。
- 商品：商品 ID、标题、状态（ACTIVE/DRAFT/ARCHIVED/UNLISTED）、品牌/供应商、商品类型、最近更新时间；按更新时间倒序分页。
- 订单：订单号（如 #1001）、下单时间、取消时间、是否测试单、付款状态、发货状态、件数、订单当前总额与币种；按下单时间倒序分页。
- 读不到：顾客身份与联系方式、收货地址、库存明细、流量、转化率、广告和利润。需要时写 unknown，或请用户提供后台导出。

## 覆盖范围

- 每次读取只是一页；汇总前记录读取页数、每页条数、是否还有 `next_page_token`。
- 应用未获得 `read_all_orders` 时 Shopify 只返回最近 60 天订单；读到的最早订单不是店铺第一单。
- 商品最近更新时间会因下单等原因变化，不能直接当作上新时间。
- 订单金额是当前总额（已反映退货、退款和改单），不是毛销售额，也不是利润。
- 读取结果带读取时间；跨对话或隔天的判断需重新读取，不沿用旧页。

## 核对与结论纪律

- 草稿、下架、归档商品数量只代表已读页；全店数量需翻完所有页，否则写明为部分页。
- 未发货积压只统计发货状态为 UNFULFILLED、PARTIALLY_FULFILLED 或 ON_HOLD，且未取消、非测试的订单，并写明时间窗口。
- 付款状态为 PENDING、AUTHORIZED 或 PARTIALLY_PAID 时只提示待跟进，不能断言欺诈或拒付。
- 测试单与已取消单单独列出，不计入经营指标。
- 多币种分别汇总；换算需要用户提供汇率及日期。
- 店铺自有商品和订单不能证明市场需求、竞品销量或品类趋势；需要市场判断时另找外部证据。
- 建议写成由人在 Shopify 后台执行的清单；OPHIRA 当前只读，任何写入都需要单独的对外动作审批。

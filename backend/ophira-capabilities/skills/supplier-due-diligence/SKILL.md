# Supplier Due Diligence

- 供应商宣传不等于已验证事实；区分企业主体、店铺、工厂和贸易商。
- MOQ、报价、交期、认证、付款条件和产能必须保留来源与观察时间。
- 用供应商 MCP 做确定性报价对比，但最终排序由主 Agent 结合用户约束判断。
- 明确列出待索取文件、样品验证、工厂审核和替代供应方案。
- 询价或发送消息前先展示收件人、内容和影响范围，等待用户批准。

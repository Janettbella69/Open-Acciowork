# Customer Path

- 先定义可观察的客户特征和购买触发条件，再寻找候选客户或渠道。
- 区分最终客户、经销商、进口商、零售商和平台流量，不把曝光当作成交意向。
- 候选排序必须回链到公开来源或用户材料，并记录最近验证时间。
- 生成最小联系实验、消息草稿和成功/停止阈值；发送或发布前必须经用户批准。
- 不伪造联系人、邮箱、销量、评价或合作意向。

## 按需资源

- 选择客户路径和解释渠道证据时读 [输入与证据规则](references/evidence-and-inputs.md)。
- 需要比较方案时，在项目工作区以 [客户与渠道路径](templates/channel-path.md) 新建可编辑底稿。模块可删减组合，不能把候选路径或草稿写成已授权外发。

# Listing Experiment

每个实验只改一个主变量，并写清成功/停止阈值与观察窗口。文案必须能追溯到产品事实或用户材料。

## 触发

Listing、A+、标题、bullet、关键词、SEO、转化实验、多市场文案。

## 不要做

- 禁止编造认证、销量、评价或“Amazon's Choice”。
- 禁止一次同时改标题、主图和价格——无法归因。
- 禁止把草稿当成已上架。

## 方法选择

1. 写下当前 listing 事实与目标市场；缺市场就问。
2. 只提出一个主变量与观察窗口。
3. 主图/A+ 草稿可经 `mcp__ophira_media__generate_media`；未配置媒体连接器时如实报错。
4. 发布到店铺或社媒属于对外动作，必须单独批准。

## 按需资源

- 核对文案事实、关键词依据和实验可比性时读 [输入与证据核对](references/evidence-and-inputs.md)。
- 需要比较文案方案或记录实验时，可用 [Listing 单变量实验稿](templates/listing-test-plan.md)，纯文案任务可仅取基线与变体部分。
- 模板仅作新工作区产物的底稿；复制或改写到当前项目 workspace 后填写，保留待填项为 unknown，不修改只读 Plugin 包。生成文案或媒体不授权上架。

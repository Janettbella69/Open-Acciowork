# 办公产物的输入、来源和核对

## 具体输入

- 明确用途、读者、所需格式、语言、截止日期与可编辑要求；已给定 XLSX/DOCX/PPTX 时保留用户选择。
- 收集数据文件/账本记录、真实路径、版本及工作表/页码范围；修订既有文件时识别需保留的公式、结构和内容。
- 报价或成本表需有产品规格、数量及单位、币种、计价单位、税费覆盖、贸易条件和有效期；缺项记 unknown。
- 确定金额精度、比例口径、时区、汇率方向和转换日期；不同币种不能直接加总。
- 如有版式、字体、品牌或模板材料，读取实际文件；未提供的品牌资产不自行冒充官方素材。

## 证据层级与核对

- 用户原始报价/业务导出是其记录的来源；外部事实另标原始 URL、发布/观察时间及适用范围。
- 供应商或用户陈述与已验证事实分列；计算值标明输入来源、公式及假设，不标成外部观察。
- 单元格、段落或幻灯片结论应能定位到真实 evidence ID、文件 sheet/行、页码或 URL；不得编造账本 ID。
- 转录时核对小数点、千分位、百分比、单位和币种；OCR 不清晰的数字不能靠上下文猜填。
- 缺失数值保留空缺或 unknown 并显示“待补”；公式不能把未报价运费或税费默认为零。
- 行间只有规格、数量档和费用范围可比时才汇总/排名；差异与过期报价单独标注。
- 引用图片、图表或附件时保留原文件和使用范围；未生成或未收到的材料列为缺口。

## 选择与输出方法

- 表格用于可复算数据，文档用于连续论证，演示稿用于逐页表达；按任务选择，不强制同时输出三种格式。
- XLSX 分开输入、计算和来源；合计、比例及差额保留公式，区分显示精度与实际计算精度。
- 对公式逐项核对引用范围、空值处理、单位和汇率方向；重算后用代表性行和总计核对结果。
- 不可比或输入缺失时显示待补而非生成最低价推荐；假设情景独立标识，不能覆盖原始报价。
- DOCX 保持标题层级、表格表头和分页可读；PPTX 每页主张与证据一致，图表轴与数字注明单位和来源。
- 用现有 office_export 或已安装 Python 能力写真实 OOXML 到 workspace；修订源文件优先另存新版本。
- 文件存在和大小仅是基础检查；重新打开核对结构、数据/公式，再用可用渲染器检查裁切、字体、表格与分页。
- 无渲染或重算能力时如实记录该项未验证，不把生成成功当作目视 QA 或公式结果验证。
- 交付真实文件并登记 Artifact，说明验证范围与未解决输入；Markdown 底稿不能冒充完成的办公文件。
- 本包模板按需复制到新 workspace 文件，不能编辑只读 Plugin；发送或签署文件另走已有授权路径。

# TradeMind product facts
> Verified: 2026-08-29
> Sources: repository `README.md`, frontend source and automated tests, https://youmind.com/overview, https://www.accio.com/work

## Existence and status
- TradeMind is the current product name for this in-development global-commerce workspace.
- The repository contains a React marketing site, a live conversation workspace, settings, memory review, evidence controls, Plugin Skills, and backend scheduled-task surfaces.
- The historical internal package/API identifiers still use `ophira` in some places for compatibility; user-facing copy uses TradeMind.

## Product definition
- Audience: cross-border businesses and trade teams.
- Purpose: connect global demand, products and supply, supply chains, customers, and transaction opportunities.
- Product journey: market signal → supply fit → route and capital validation → buyer test → real transaction.
- Current homepage proposition: “Go beyond borders. From product idea to global sales.”
- Product architecture: one shared project truth across demand, supply, capital, and sales, with the weakest dimension driving the next validation action.

## Evidence and honesty boundary
- Commercial examples on the marketing page are prompts and capability examples, not customer outcomes.
- The page does not claim customer counts, revenue, completed transactions, testimonials, or performance metrics.
- The “ONE / TRUE / READY / LIVE” section describes product properties, not adoption statistics.

## Current reference snapshot
- YouMind's current overview uses a quiet navigation bar, an input-led hero, mode selectors, editorial capability chapters, and an output gallery. TradeMind borrows that information rhythm only.
- Accio Work currently presents an AI business-work category with Agent teams, workspaces, memory, Skills, and scheduled work. TradeMind uses this only as a category reference and retains one main Agent in the normal execution path.

## Reference boundary
- YouMind is used as a current reference for information rhythm: quiet navigation, an input-led hero, editorial typography, generous whitespace, visual storytelling, and a consistent composer between marketing and product.
- Accio Work is used as a product-category reference, not as a source for TradeMind copy, page structure, or interaction details.
- TradeMind copy, visual assets, opportunity examples, product UI, and global-commerce narrative are original to this repository.

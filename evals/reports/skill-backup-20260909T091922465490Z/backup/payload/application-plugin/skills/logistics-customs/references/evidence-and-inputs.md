# 进口路线、税负和时效的输入与证据

## 具体输入

- 明确产品用途、材质/成分、加工形态、规格与型号；缺关键归类特征时记录 unknown 并补问。
- 原产国、发运国和目的国分列，记录进口辖区、计划入境日期及进口主体；不能用发货地址推定原产地。
- 收集数量/单位、货值/币种、包装件数、尺寸及单位、毛重/净重、运输方式和起讫地点。
- 报价记录 Incoterms 版本与指定地点、费用包含/排除、报价有效期、运输时效起算点和是否为工作日。
- 现有 HS 候选、归类意见、原产地证明及优惠资格均需真实出处；没有材料不假设享受优惠税率。

## 证据层级与核对

- 目的国官方税则、海关裁定和限制清单支持明示适用范围；记录 URL、条目/编码位数、适用国家、版本与生效日。
- 报关行归类建议保留文件位置、日期和所基于的产品描述；它不是海关已作出的裁定。
- 承运人/货代报价支持对应路线和窗口的费用、预计时效；用户经验与社区案例单列为陈述或线索。
- 每个税率、限制条件和费用链接真实 evidence ID 或已读 URL/文件页码；检索时间不能替代规则生效时间。
- 核对最惠国/优惠/附加或贸易救济税的适用条件与组合关系；查不到不是税率为零。
- 目的国本地编码与国际 HS 层级不能混用；同名商品需核对材料、用途和章节注释后再列候选。
- 费用标明币种、每票/每柜/每公斤等单位；计费重规则与最低收费需报价依据，不用默认系数猜算。
- 官方来源过期、不可读或互相冲突时保留原文日期与差异，将受影响结论设为待确认。

## 选择与输出方法

- 按产品特征列有出处的 HS 候选及排除理由，明确尚需报关行/海关确认的问题；不生成虚构编码。
- 按路线比较相同服务范围，单列港杂、末端配送、仓储和查验等未包含项，不把未知费记作零。
- 时效区分生产、提货、干线、清关和末端；报价预计日期不等于保证到货日期。
- 现有 calculate_landed_cost 使用：税基 = 货值 + 运费 + 保险；关税 = 税基 × duty_rate；税 = (税基 + 关税) × tax_rate。
- 只有该公式符合有依据的适用税制时才作为税负测算；工具不判断归类、优惠资格或实际应税价格。
- 从量税、复杂附加税、不同税基或可抵扣税的经济成本不由该简化公式证明；列出缺口，不强塞为单一税率。
- 工具费率使用小数表示，金额先统一币种并保留真实汇率来源/日期；确定性结果标为计算，不称官方税单。
- 缺税率或费用时可输出已知成本与待补项；假设情景须由明确假设构成，不能用臆造税率冒充现行规则。
- 输出路线、候选依据、费用覆盖、时效与未决事项；模板按需写入新 workspace，不代表已订舱、申报或获批。

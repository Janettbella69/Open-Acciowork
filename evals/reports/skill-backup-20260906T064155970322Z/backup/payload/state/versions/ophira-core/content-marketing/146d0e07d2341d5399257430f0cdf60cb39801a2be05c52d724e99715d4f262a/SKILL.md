# Content Marketing

脚本与文案必须绑定产品事实与目标市场约束。

## 触发

TikTok、脚本、社媒、内容日历、跨境内容营销、广告文案草稿。

## 不要做

- 禁止编造销量、评价或认证。
- 禁止把草稿当成已发布。
- 未配置媒体连接器时不得发明像素。

## 方法选择

1. 每条内容标注平台、语言、主张来源。
2. 配图草稿走 `generate_media`；未配置时说明缺口。
3. 用实验而不是直觉：一条主信息、一个 CTA、一个停止条件。
4. 外发/发布单独授权。

## 按需资源

- 选择内容主张、核对素材权利或设计指标时读 [输入与证据核对](references/evidence-and-inputs.md)。
- 需要短视频或社媒内容草稿时，可用 [内容与实验简报](templates/content-experiment-brief.md)，按渠道选取脚本或图文部分。
- 模板仅作新工作区产物的底稿；复制或改写到当前项目 workspace 后填写，保留待填项为 unknown，不修改只读 Plugin 包。模板不授权外发或发布。

# 市场假设与证据口径

## 研究前的最少输入

- 明确品类/用途、目标市场、客户类型、观察期间和用户这次要做的判断。产品定义过宽或地区不明会使规模与竞争比较失真。
- 写一个可被反证的假设及什么发现会改变判断；用户只要求整理资料时不强行代做市场进入决策。
- 明确已经有的原始材料、可用搜索/数据服务与不可访问来源；不能把配置缺失或访问失败描述为“市场不存在”。

## 证据覆盖范围

- 公开统计/原始研究：核对发布机构、数据年份、地域、品类定义、采集方法及更新/修订。引用的规模只能覆盖其实际口径。
- 搜索/平台页面：记录查询词、地区、语言、筛选、时间窗口、采样页及观察时间；排名、热度指数和评论数不等于实际销量。
- 竞品材料：注明规格、数量/包装、币种、含税/运费范围、促销和抓取时间；价格挂牌与成交价分开。
- 用户销售/访谈记录：保留原文件定位、样本范围和缺失字段。不能把单一客户或一个视频外推为总体需求。
- 证据分为 `observed_fact`、`user_statement`、`community_signal`、`inference`；关键数字必须有原文定位及单位、时间。URL本身不表示已访问，真实 receipt/Evidence ID 只从宿主结果取得。

## 检索与归纳

- 优先寻找能支持或推翻假设的原始来源，同时留意反证。转载同一研究不算多个独立样本。
- 相同词在不同地区、语言或统计定义中可能不同；先列不可比点，不能将不同年份/分母直接加总或计算增长。
- 出现冲突时保留各自口径，解释可信度与相关性差异。无法解释就把冲突作为决策限制。
- 时机分档只是一种推断表达。没有足够时间序列与竞争证据时写“无法判断”，不能为了报告完整强制 Early/Peak/Saturated。
- 区分没有发现证据与发现了反证；检索覆盖有限时明确范围。

## 输出选择

按需使用 [市场证据简报](../templates/market-evidence-brief.md)。先写最能回答问题的结论，再附证据与缺口；可用一个下一项验证替代庞大的行动清单。涉及收费研究、授权数据或外部动作时说明依赖，不声明已经购买、连接或执行。

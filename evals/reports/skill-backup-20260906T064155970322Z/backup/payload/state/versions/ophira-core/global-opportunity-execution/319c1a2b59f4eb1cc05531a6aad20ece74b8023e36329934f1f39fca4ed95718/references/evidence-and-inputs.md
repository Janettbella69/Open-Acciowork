# 从任意业务起点形成可核对判断

## 先确认什么

- 记录用户这次希望决定的具体问题，以及最终交付给谁使用。发现机会、比较候选和准备执行材料可以有不同的完成条件。
- 从现有需求、产品/产能、客户线索或市场信号出发，先用已有项目材料；只追问会改变推荐方向的关键约束，例如目标市场、预算边界、时间和不能接受的风险。
- 将用户已确认的约束与 Agent 建议的假设分开。资金、销售等视角仅在影响当前判断时使用，不要求四份分析或顺序过关。

## 哪些证据能支持哪种判断

依照 [原有证据规则](evidence-rules.md) 保留四种来源性质。每条关键主张还要说明它支持的具体决策、覆盖范围，以及不能据此推导的结论。

- 市场需求：公开统计、真实询盘/订单或客户访谈材料可支持其实际覆盖的样本；平台排名、搜索量和讨论只能支持相应的代理信号判断。
- 供给可达性：有效报价、样品结果和可定位的资质材料分别支持价格条件、样品表现、资质范围，不能互相替代。
- 客户路径：公开渠道角色和用户联系记录可支持候选与接触状态；浏览/曝光不证明购买意愿。
- 经济性：先列币种、期间、数量、税费口径与缺失输入，再调用确定性计算。测算不是到账现金或真实成交。
- 来源账本有 receipt / Evidence 时引用宿主生成的真实 ID；没有 receipt 时保留 URL/文件定位、获取时间和“未入账/待核对”状态，不能编造已验证锚点。

## 比较与停止

- 比较同一口径、同一时间范围的候选；样本不足、观察过旧或利益相关方自述时降低结论强度，而非补造精确分数。
- 支持和反对证据并列。冲突可能来自地区、规格、币种、期间或来源身份不同，未查明前不做简单平均。
- 选择最可能改变判断的下一项验证，写出可观察的成功/停止条件及谁有权执行。不要为了填满模板检索无关资料。
- 将结论与假设、适用条件、待补信息分开。没有足够材料时交付“暂不能判断 + 如何补证”，不强行给 Go。

## 可编辑输出

按需使用 [机会判断简报](../templates/opportunity-brief.md)。只填写与任务相关的模块；用户需要时再与具体领域 Skill 的产物组合。引用 Evidence/Decision/Artifact 时保留真实标识；外发、下单、付款与新建长期自动化仍需各自授权。

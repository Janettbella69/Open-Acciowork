# Customer Development

- 先定义可观察的购买触发，再排序候选；排序必须回链公开来源或用户材料。
- 用 `record_interaction` 记下联系实验，不把曝光当成交意向。
- 消息草稿可写，发送必须经用户批准。不伪造邮箱、职位或合作意向。
- 成功/停止阈值写进项目决策，避免无限跟进。

## 按需资源

- 核对客户信号、联系人与互动记录时读 [输入与证据规则](references/evidence-and-inputs.md)。
- 具体开发实验可在项目工作区用 [客户开发记录](templates/account-development.md) 新建可编辑底稿。只保留相关模块；拟联系、已发送、已回复分别记录，不修改 Plugin 模板或代替授权发送。

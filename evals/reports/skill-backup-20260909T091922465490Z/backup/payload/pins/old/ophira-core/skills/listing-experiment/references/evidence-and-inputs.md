# Listing 文案与实验的输入和证据

## 具体输入

- 明确平台、站点/市场、语言、品类、SKU/变体及目标页面；缺市场会影响规则时补问，其他缺项记 unknown。
- 保存当前标题、要点、主图/A+、价格与库存状态的真实页面或用户文件，注明抓取时间和版本。
- 收集规格、材质、尺寸/重量及单位、包装清单、使用边界和有效的产品证明；区分单品与整包数值。
- 实验需有目标、可用流量/订单数据、统计窗口与时区、变体分流方式及允许改动的范围。
- 用户只要文案时直接产出可审阅草稿；缺实验数据不妨碍事实清楚的文案整理。

## 证据层级与核对

- 产品材料或可复核测量支持事实；用户及供应商陈述单列，不把营销承诺升级为实测结论。
- 平台官方规则支持标题、图片、禁限词与 A+ 约束；保留 URL、适用站点/品类、日期及核验时间。
- 后台导出支持其时间窗口内的指标；保留文件位置、过滤条件、分母、归因窗口及订单去重口径。
- 关键词工具或搜索观察保留真实查询、市场、时间与来源；无搜索量数据时写 unknown，不推定热度数值。
- 竞品页面和评论支持语言线索及待验证痛点，不能证明本品功能、销量、评价或获得平台徽章。
- 每条产品主张链接真实 evidence ID 或已读取文件页/行、URL；标题里的数字也需要该锚点。
- 翻译需保留适用条件和单位换算依据；不能用当地常见说法增加未证实的安全、健康或认证承诺。
- 无媒体连接器时仅交付文字与素材需求；生成结果需检查外观、附件和包装是否与事实一致。

## 选择与输出方法

- 文案先确定一个有证据的价值点，再选择标题、要点或 A+ 区块表达；关键词必须相关且符合当前站点规则。
- 实验定义一个主变量与可复现的对照/变体版本，保持价格、投放等条件稳定并记录实际偏差。
- 平台支持同时分流时记录分配与实验单位；只有先后版本时说明季节、库存和促销影响，不能直接声称因果。
- 指标需明确分子、分母与观察窗口；比较转化率先核对流量口径，不能拿点击率代替购买转化率。
- 成功/停止阈值应有用户约束或历史依据；缺依据写为待确认假设，不预先填入胜出结果。
- 样本量、最低观察期和归因延迟按数据条件设计；不以单日波动、未成熟订单或随时偷看宣称显著提升。
- 输出可编辑变体、事实映射、实验条件及结果局限；证据不足时保留继续观察或无法判断。
- 模板仅用于新 workspace 产物；上架、改价或开启平台实验仍须已有授权及对应可用连接器。

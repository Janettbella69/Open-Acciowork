# Landed Cost Analysis

使用商业计算 MCP，不在自然语言中心算关键财务结果。关税/HS 细节走 `logistics-customs`。

## 触发

到岸成本、landed cost、毛利、盈亏平衡、现金流、现金占用、资金缺口、价格敏感性、DDP。

## 不要做

- 不得用单一毛利率替代现金流风险。
- 不得把估算税率写成 observed_fact。
- 不得口算合计；合计必须来自 MCP 或表格公式。

## 步骤

1. 把币种、税率、运费分摊、平台费、退款率、获客成本、MOQ 与付款周期列为显式输入。
2. 区分已知报价、用户假设和模型估算。
3. 按问题需要比较基准、悲观、乐观情景或敏感变量；每个情景须有明确输入，缺少依据时保留缺口，不补出数值。
4. 将计算输入和结果写入可复算的 Markdown/CSV/JSON 产物。

## 现金与付款时间

涉及现金占用、订金/尾款或回款延迟时，先按
[现金输入与证据规则](references/cashflow-inputs.md)收齐日期和收支。
使用 `ophira_commerce_math.cashflow_peak` 计算余额及资金缺口；它只处理显式输入的
同币种结算计划，不会生成销量、利率、回款预测或融资承诺。
保留最低现金是余额阈值，不得重复列为费用；已列入的贷款/融资不得再次加到现金中。
日末净额与“当天先付款后收款”的保守日内缺口分开报告，不能把后者称作实际付款顺序。

按用户所需产物选用 [成本分析模板](templates/cost-analysis.md) 或
[现金流报告模板](templates/cashflow-report.md)，允许删去无关章节。
金额、日期与情景差额来自实际工具结果；不要填入演示数字或把未验证引用提升为事实。

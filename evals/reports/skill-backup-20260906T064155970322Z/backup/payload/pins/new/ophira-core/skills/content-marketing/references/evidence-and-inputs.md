# 跨境内容的输入和证据

## 具体输入

- 明确平台、市场、语言、受众、产品型号、内容目的与预期动作；缺失写 unknown，不能凭语言推定国家。
- 收集经核对的功能、规格、价格/促销有效期、售卖区域及禁用措辞；价格记录币种、税费和单位。
- 素材需给出文件路径、版本、可用范围、权利声明与人物使用授权状态；用户持有文件不自动证明可商业使用。
- 如需实验，收集已有内容、发布时间/时区、分发方式、预算和平台后台导出；无历史数据可保留基线 unknown。
- 选择指标前确定转化事件、统计窗口、分母和去重方式；播放量不能替代成交量。

## 证据层级与核对

- 产品说明、实测记录和真实用户材料支持对应产品事实；供应商自述单列为陈述，不能扩大为独立验证。
- 平台官方政策支持当前内容或广告限制，记录原始 URL、适用市场、版本/日期及核验时间。
- 后台导出支持其覆盖窗口内的播放、点击或订单观察；保留文件、sheet/行、时区及指标定义。
- 热门话题、竞品内容和评论是创意或需求线索；记录 URL、观察时间与样本，不编造成搜索量或销量。
- 每个可验证主张关联真实 evidence ID 或已读材料位置；脚本的创意解释标作建议，不能冒充实测结论。
- 展示评价、获奖和认证前核对原文、产品范围及授权；缺原始依据时删除该主张或标为内部待证。
- 演示、情景演绎与真实客户经历分开描述；不要编造亲身体验、客户证言或购买记录。
- 无可用媒体连接器时保留分镜/素材需求，明确生成未完成；不把提示词写成已生成资产。

## 选择与输出方法

- 教育、演示、比较或促销内容按受众疑问选择；每条聚焦一个有证据的主信息与一个 CTA。
- 短视频写出时长、镜头、口播、屏幕文字和所需素材；图文写出各页信息与阅读顺序。
- 本地化时核对单位、货币、文化语境和优惠期限，翻译不能新增原材料未支持的功效或承诺。
- 生成媒体仅调用已配置能力，检查生成结果是否误画标志、包装或未存在的产品特征。
- 实验写明一个主变量、比较对象、观察窗口、目标指标和停止条件；阈值无数据时写待用户设定的假设。
- 比较需说明自然/付费流量及投放差异；样本少或归因窗口未结束时保留“证据不足”。
- 输出文案、事实对照、素材清单和实验记录；已有数据可直接分析，不强制先建立内容日历。
- 草稿写入新 workspace 产物；素材生成不等于发布，只有明确授权的内容、账号和渠道可走现有发布路径。

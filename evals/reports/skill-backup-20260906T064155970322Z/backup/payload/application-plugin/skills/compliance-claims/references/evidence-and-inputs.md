# 宣称、标记与标签的输入和证据

## 具体输入

- 明确目的市场及辖区、销售渠道、产品型号/版本、用途、使用人群、材质与接触方式；缺失写 unknown。
- 收集待审原文及语言、所在标签/详情页/包装位置、拟上线日期；把一段话拆成可单独验证的主张。
- 用户提供的检测报告、声明、注册信息与标签图需保留文件版本、页码、签发主体、日期及适用型号。
- 成分含量、性能值与测试条件保留单位、方法和样本范围；不能把单个条件下的结果推广到所有使用情形。
- 缺目标市场或产品用途会改变适用规则时，先补问该缺口；仍可整理已有材料和待核对清单。

## 证据层级与核对

- 官方法规/监管指南支持适用要求；记录真实 URL、条款/段落、发布日、生效日、核验时间与辖区。
- 平台政策支持平台准入或文案限制，单列来源和版本；不自动视为国家法规。
- 实验室报告、符合性声明和注册条目只支持其明示范围。核对主体、型号、标准版本、结果、有效期及可验证编号。
- 供应商口头说明或用户转述标作陈述；论坛和同行页面只作为寻找问题的线索，不证明合规。
- 内置 lookup_requirements 是随包资料检索，返回时间不等于法规更新日期；无匹配不代表无要求。
- 每条结论链接真实 evidence ID 或已读取的 URL/文件页码；不得生成看似真实的报告编号、证据 ID 或证书。
- 搜索摘要、图片上的标志与“拥有证书”说法不足以证明适用性；无法读取原文或校验范围时写 unknown。
- 规则冲突时保留双方适用范围和日期，解释尚未解决的分歧，不自行拼出一项批准结论。

## 选择与输出方法

- 按主张判断“依据支持的限定表述 / 需改写 / 暂缓使用”；认定禁止须指出适用的明确依据。
- 对功效或性能宣称先核对测量对象和条件，再拟定不超出报告范围的用语；改写建议标为推断草稿。
- 对标记核对使用资格和产品范围；公司注册、产品列名、检测通过与监管批准不能互换。
- 对缺证据的主张列出需补文件、核对人和阻断原因；不要靠加入模糊免责声明保留无依据主张。
- 将可保留原文、建议改文、证据锚点和未决问题并排输出，方便逐条审阅。
- 没有证据支持的销量、认证与合规状态保持 unknown；不填“已通过”来完成模板。
- 结论注明材料截止日期；拟发布时如产品、市场、用途或规则版本改变，重核受影响主张。
- 模板可按需要裁剪，在新 workspace 文件中填写；对外发布、签署声明或申请认证须走已有授权路径。
